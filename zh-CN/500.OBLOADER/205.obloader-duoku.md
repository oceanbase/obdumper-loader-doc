# 多库导入

OBLOADER V4.3.5 及之后版本在兼容原有单独导入行为不变的前提下，新增支持一次命令导入多个数据库对象的功能。

## 功能介绍

多个数据库的导入功能是在命令中，根据您指定的对象表达式 `<schema.object>`（例如，`test.table1`、`test1.*`、`*.*` 等），指定需要导入的对象范围。

多库导入在识别出将要导入的库和对象后，会打印导入清单并要求您进行确认，您可以使用 `-y` 跳过确认。

## 功能实现

### 单库模式

当 `--table`、`--view` 等对象参数中不包含特定的数据库 Schema，即不存在英文句号（.）时，根据原有逻辑判断是单库导入，保持原有行为不变。

### 多库模式

只要任一对象参数值包含特定的数据库 Schema，即存在英文句号（.）时，则进入多库导入模式。例如，`test.table1`、`test1.*` 或 `*.*`。

多库模式在实现上不改变初始命令行解析，而是将一条多库导入命令拆分为多条按库执行的单库导入命令。具体说明如下：

* 对 `--table`、`--view` 等对象参数进行解析，分发 `<schema.object>` 至对应 Schema 的子任务中，分别指定导入范围。

* 如果某个对象未包含特定的数据库 Schema（例如，`*`），则使用 `-D` 指定的默认数据库，其他选项保持不变。

拆分示例如下：

```shell
obloader -D test --table 'test1.*,test2.*' ...
-> obloader -D test1 --table * ...
-> obloader -D test2 --table * ...

obloader -D test --table '*,test2.*' ...
-> obloader -D test --table * ...
-> obloader -D test2 --table * ...
```

默认导入目录结构匹配多库导出形成的数据集，即数据库（Schema）层级目录。示例如下：

```shell
/output
    └── data
            ├── test1
            │     └── TABLE
            │         ├── sample_tbl1.csv
            │         └── sample_tbl2.csv
            ├── test2
            │     └── TABLE
            │         ├── sample_tbl3.csv
            │         └── sample_tbl4.csv
            └── test3
                    └── TABLE
                        ├── sample_tbl5.csv
                        └── sample_tbl6.csv
```

多库导入会根据 `<schema.object>` 定位到对应 Schema 目录下的数据进行导入。在实际执行前，命令行将会打印识别到的 **将要导入的库/对象** 清单并要求您进行确认。如果您无需确认，则可以使用 `-y` 选项跳过后直接执行。

<main id="notice" type='notice'>
<h4>注意</h4>
<ul>
<li>多库目录结构下，默认根据库名原样导入。例如，<code>/output/data/test2/...</code> 对应导入目标端 test2 库。除非您显式指定单库导入路径（例如，通过 <code>-f</code> 参数指向某个具体的库子目录），并使用不包含英文句号（.）的对象参数触发单库逻辑。</li>
<li>不支持数据库名存在 <code>[</code> 或 <code>{</code> 的场景，否则您需要进行转义或特别指定才能够顺利导入。</li>
</ul>
</main>

## 场景示例

### 场景一：单库导入（不受影响）

* 将 `/output` 导出的 `test` 库导入回 `test`。

    ```shell
    ./obloader -h xx.x.x.x -P 2883 -u test@mysql#cluster_a -p ****** 
    -D test --csv --table '*' -f /output
    ```

* 将 `/output` 导出的 `test` 库导入至另一个库 `test1`。

    ```shell
    ./obloader -h xx.x.x.x -P 2883 -u test@mysql#cluster_a -p ****** 
    -D test1 --csv --table '*' -f /output
    ```

### 场景二：多库导出 + 多库导入（按库原样导入）

前置操作：您通过下述命令，多库导出 `test1`、`test2` 和 `test3` 库。

```shell
./obdumper -h xx.x.x.x -P 2883 -u test@mysql#cluster_a -p ****** 
--csv --table 'test[1-3].*' -f /output
```

<main id="notice" type='notice'>
<h4>注意</h4>
<p>多库数据集下，多个数据库文件夹只能导入对应的同名数据库中（例如，<code>test2</code> 文件夹导入 <code>test2</code> 库）。该行为是多库导入模式的默认行为。</p>
</main>

* 导入全部数据库

  * 方式一

    ```shell
    ./obloader -h xx.x.x.x -P 2883 -u test@mysql#cluster_a -p ****** 
        --csv --table 'test[1-3].*' -f /output
    ```

  * 方式二

    ```shell
    ./obloader -h xx.x.x.x -P 2883 -u test@mysql#cluster_a -p ****** 
        --csv --table '*.*' -f /output
    ```

  * 方式三

    ```shell
    ./obloader -h xx.x.x.x -P 2883 -u test@mysql#cluster_a -p ****** 
        --csv --table 'test1.*, test2.*, test3.*' -f /output
    ```

* 仅导入数据库 `test1` 和  `test2`

  * 方式一

    ```shell
    ./obloader -h xx.x.x.x -P 2883 -u test@mysql#cluster_a -p ****** 
        --csv --table 'test[1-2].*' -f /output
    ```

  * 方式二

    ```shell
    ./obloader -h xx.x.x.x -P 2883 -u test@mysql#cluster_a -p ****** 
        --csv --table 'test1.*,test2.*' -f /output
    ```

  * 方式三

    ```shell
    ./obloader -h xx.x.x.x -P 2883 -u test@mysql#cluster_a -p ****** 
        --csv --table 'test1.*' --table 'test2.*' -f /output
    ```

### 场景三：多库导出 + 单库导入（多个库导入至一个库）

导出多个数据库后，将其导入至同一个数据库的关键在于 `-f` 参数，会影响执行多库导入还是单库导入。

前置操作：您通过下述命令，多库导出 `test1`、`test2` 和 `test3` 库。

```shell
./obdumper -h xx.x.x.x -P 2883 -u test@mysql#cluster_a -p ****** 
  --csv --table 'test[1-3].*' -f /output
```

* 导出数据集中的 `test2` 导入至 `test2`。该场景执行多库导入逻辑，使用 `test2.*` 来指定库。

    ```shell
    ./obloader -h xx.x.x.x -P 2883 -u test@mysql#cluster_a -p ****** 
    -D test --csv --table 'test2.*' -f /output
    ```

* 将导出的 `test1` 子目录作为单库输入，导入至目标库 `test` 中。该场景执行单库导入逻辑。

    ```shell
    ./obloader -h xx.x.x.x -P 2883 -u test@mysql#cluster_a -p ****** 
    -D test --csv --table '*' -f /output/test1
    ```

* 指向根目录并使用 `--table '*'`，将 `test1`、`test2` 和 `test3` 库混合作为单库输入导入至 `test`。该场景执行原有的单库导入逻辑。

    ```shell
    ./obloader -h xx.x.x.x -P 2883 -u test@mysql#cluster_a -p ****** 
    -D test --csv --table '*' -f /output
    ```

    <main id="notice" type='explain'>
    <h4>说明</h4>
    <p>多个数据库导入至一个数据库，本质执行的是原有单库导入逻辑（由 <code>-f</code> 选择输入目录形态触发）。 </p>
    </main>

### 场景四：租户级导入（按库原样导入）

全量导入全部库的全部对象，包含定义和数据。

<main id="notice" type='notice'>
<h4>注意</h4>
<p>不支持数据库名存在 <code>[</code> 或 <code>{</code> 的场景，否则您需要进行转义或特别指定才能够顺利导入。</p>
</main>

```shell
./obloader -h xx.x.x.x -P 2883 -u test@mysql#cluster_a -p ****** 
  --table '*.*' --ddl --csv --all -f /output
```
