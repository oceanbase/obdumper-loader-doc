# 命令行应用示例

本文为您介绍一些常用或应用于复杂场景的命令行使用示例。

## --auto-column-mapping

### 场景描述

将 `/home/admin/obloader` 目录下的表 `my_table`的 CSV 文件（列名分别为 col1、col2 和 col3）导入至数据库 `obloader` 中，目标表的列名分别为 col2、col3 和 col4。

* 源端表数据

    ```shell
    $cat my_table.csv
    'col1','col2','col3'
    'data1',1,'desc1'
    'data2',2,'desc2'
    'data3',3,'desc3'
    ```

* 目标端表结构

    ```shell
    obclient [obloader]> DESC my_table;
    +-------+--------------+------+------+---------+-------+
    | Field | Type         | Null | Key  | Default | Extra |
    +-------+--------------+------+------+---------+-------+
    | col2  | int(11) | YES  |      | NULL    |       |
    | col3  | varchar(255)     | YES  |      | NULL    |       |
    | col4  | varchar(255) | YES  |      | NULL    |       |
    +-------+--------------+------+------+---------+-------+
    3 rows in set (0.035 sec)
    ```

### 不使用 --auto-column-mapping

对于列名不一致但列类型一致的情况，可能会忽略列名进行导入，导致数据不一致的问题，请注意确认。

1. 执行导入命令。

    ```shell
    ./obloader -h xxx.xxx.xxx.xxx -P xxxx -u test@mysql -D obloader --csv --table 'my_table' -f /home/admin/obloader
    ```

2. 等待命令执行结果，预期会报错。

3. 在数据库查询目标表数据，未成功导入。

    ```sql
    SELECT * FROM my_table;
    ```

    查询结果如下：

    ```sql
    obclient [obloader]> SELECT * FROM my_table;
    Empty set (0.035 sec)
    ```
  
### 使用 `--auto-column-mapping`

1. 执行导入命令。

    ```shell
    ./obloader -h xxx.xxx.xxx.xxx -P xxxx -u test@mysql -D obloader --csv --table 'my_table' --auto-column-mapping -f /home/admin/obloader
    ```

2. 等待命令执行结果，预期会导入源端 col2 和 col3 的数据，col4 会填充默认值。

3. 在数据库查询目标表数据，符合预期。

    ```sql
    SELECT * FROM my_table;
    ```

    查询结果如下：

    ```sql
    obclient [obloader]> SELECT * FROM my_table;
    +------+---------+------+
    | col2 | col3    | col4 |
    +------+---------+------+
    |    1 | desc1   | NULL |
    |    2 | desc2   | NULL |
    |    3 | desc3   | NULL |
    +------+---------+------+
    3 rows in set (0.033 sec)
    ```
