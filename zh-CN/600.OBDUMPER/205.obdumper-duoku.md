# 多库导出

OBDUMPER V4.3.5 及之后版本在兼容原有单库导出行为不变的前提下，新增支持一次命令导出多个数据库对象的功能。

## 功能实现

### 单库模式

当 `--table`、`--view` 等对象参数中不包含特定的数据库 Schema，即不存在英文句号（.）时，根据原有逻辑判断是单库导出，使用 `-D` 指定的默认数据库。

### 多库模式

只要任一对象参数值包含特定的数据库 Schema，即存在英文句号（.）时，则进入多库导出模式。例如，`test.table1`、`test1.*` 或 `*.*`。

多库模式在实现上不改变初始命令行解析，而是将一条多库导出命令拆分为多条按库执行的单库导出命令。具体说明如下：

* 对 `--table`、`--view` 等对象参数进行解析，分发 `<schema.object>` 至对应 Schema 的子任务中，分别指定导出范围。

* 如果某个对象未包含特定的数据库 Schema（例如，`*`），则使用 `-D` 指定的默认数据库，其他选项保持不变。

拆分示例如下：

```shell
obdumper -D test --table 'test1.*,test2.*' ...
-> obdumper -D test1 --table * ...
-> obdumper -D test2 --table * ...

obdumper -D test --table '*,test2.*' ...
-> obdumper -D test --table * ...
-> obdumper -D test2 --table * ...
```

默认导出目录结构会在原有目录层级上，增加数据库（Schema）层级目录。示例如下：

```shell
/output
    └── data
            ├── test1
            │     └── TABLE
            │         ├── sample_tbl1.csv
            │         └── sample_tbl2.csv
            ├── test2
            │     └── TABLE
            │         ├── sample_tbl3.csv
            │         └── sample_tbl4.csv
            └── test3
                    └── TABLE
                        ├── sample_tbl5.csv
                        └── sample_tbl6.csv
```

<main id="notice" type='notice'>
<h4>注意</h4>
<p>不支持数据库名存在 <code>[</code> 或 <code>{</code> 的场景，否则您需要进行转义或特别指定才能够顺利导出。</p>
</main>

## 场景示例

### 场景一：单库导出（不受影响）

导出 `test` 库至 `/output`。

```shell
./obdumper -h xx.x.x.x -P 2883 -u test@mysql#cluster_a -p ****** 
  -D test --csv --table '*' -f /output
```

### 场景二：多库导出（一次导出多个库）

* 方式一

    ```shell
    ./obdumper -h xx.x.x.x -P 2883 -u test@mysql#cluster_a -p ****** 
    --csv --table 'test[1-3].*' -f /output
    ```

* 方式二

    ```shell
    ./obdumper -h xx.x.x.x -P 2883 -u test@mysql#cluster_a -p ****** 
    --csv --table 'test1.*, test2.*, test3.*' -f /output
    ```

* 方式三

    ```shell
    ./obdumper -h xx.x.x.x -P 2883 -u test@mysql#cluster_a -p ****** 
    --csv --table 'test1.*' --table 'test2.*' --table 'test3.*' -f /output
    ```

### 场景三：租户级导出（间接实现全租户导出）

全量导出全部库的全部对象，包含定义和数据。

<main id="notice" type='notice'>
<h4>注意</h4>
<p>不支持数据库名存在 <code>[</code> 或 <code>{</code> 的场景，否则您需要进行转义或特别指定才能够顺利导出。</p>
</main>

```shell
./obdumper -h xx.x.x.x -P 2883 -u test@mysql#cluster_a -p ****** 
  --table '*.*' --ddl --csv --all -f /output
```
