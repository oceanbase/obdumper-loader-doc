# 导数工具 V4.3.5

本次发版的导数工具 V4.3.5 进一步支持多数据库逻辑迁移场景，新增多库导入导出功能、增加 CSV 解析对齐 RFC 4180 规范以提升兼容性和稳定性、优化自动列映射等，并集中修复一些已知缺陷，进一步提升导数工具的稳定性和易用性。

## 新增特性

* 新增旁路导入对含非可见列表的支持功能，解决用户在导入包含隐藏列的表时，因列不可见而导致任务失败的使用问题。

* 新增旁路导入对数据文件与表定义列顺序、列数量不一致的兼容功能，解决用户在源数据文件列顺序或字段数量与目标表结构不完全匹配时，仍需要手动预处理数据的使用问题。

* 新增单次旁路导入任务支持多表写入的功能，解决用户需要为每张表单独发起导入任务，操作繁琐且效率低下的使用问题。

* 新增跨数据库/Schema 的批量对象和数据导入导出功能，解决用户在迁移或备份多个数据库/Schema 时，需要多次配置和执行任务的使用问题。

* 新增 CSV 数据解析全面兼容 RFC 4180 规范的功能，解决用户在处理包含引号、换行符或转义字符等复杂内容的 CSV 文件时，因解析不标准而导致数据错位或导入失败的使用问题。

* 新增 OceanBase 数据库 Oracle 兼容模式下支持 ROWID 和 UROWID 类型数据导入导出的功能，解决用户在 OceanBase 数据库 Oracle 模式下无法导入导出包含 ROWID 和 UROWID 类型列的表的使用问题。

* 新增在 CUT 格式数据导入场景下支持 `--ignore-escape` 以禁用转义的功能，解决用户在导入包含分隔符或特殊字符但无需转义处理的原始文本数据时，因系统强制解析转义序列而导致字段内容被错误修改或解析失败的使用问题。

## 缺陷修复

* 修复无法写入 null 字符串至 JSON 类型的列中的问题。

* 修复旁路导入时，commit 时间被一直计算为 0 的问题。

* 修复导入包含 \ 或 \\\ 的存储过程时，报错 No statements are parsed 的问题。

* 修复导入包含 # 的存储过程时，报错 No statements are parsed 的问题。

* 修复结构导入时，报错信息 Dependencies are missing 含义不明确的问题。

* 修复导入表对象时，可能会出现的因为外键约束而导致导入失败的问题。

* 修复 OceanBase 数据库 MySQL 兼容模式下，旁路导入包含二进制类型的数据过程中数据内容失真的问题。

* 修复 OceanBase 数据库 MySQL 兼容模式下，旁路导入包含 bit、binary 和 varbinary 类型的数据过程中，报错 OB_ERR_DATA_TOO_LONG 的问题。

* 修复 OceanBase 数据库 Oracle 兼容模式下，导出末尾包含注释的视图对象时，视图末尾的分号被包含在注释中，从而导致无法再被导入的问题。

* 修复 OceanBase 数据库 MySQL 兼容模式下，使用哈希密码锁创建用户语法错误的问题。

* 修复导出时，使用 `--table *` 或 `--all` 无法引用对应的控制文件的问题。

* 修复导入存在空行的 CUT 文件时，直接忽略空行后面的数据的问题。

* 修复 OceanBase 数据库 Oracle 兼容模式下，导出用户定义时权限遗漏数据库信息的问题。

* 修复导出 POS 格式文件且在控制文件中不指定 position() 方法会导致空异常的问题。

* 修复导出表对象时，将物化视图也一并导出的问题。

* 修复导出表对象时，可能出现的 materialized view log 相关报错的问题。

* 修复 OceanBase 数据库 MySQL 兼容模式下，使用 `--all` 导出地址包含 % 通配符的用户对象出现语法错误的问题。

* 修复 secure-gen 脚本在确认是否覆盖生成加密文件时出现报错的问题。

* 修复 `--query-sql` 模式下不支持导出 Parquet 格式文件的问题。

* 修复 `--type-body` 选项无效的问题。

* 修复使用 `--query-sql` 导出 SQL 文件时，报错 The column type is null 的问题。

* 修复 `--table` 使用通配符匹配表对象时，`--exclude-table` 参数失效的问题。

* 修复无法导入由 OBDUMPER 导出的包含隐藏列 SYS_SESSION_ID 的临时表的问题。

* 修复 `--max-errors` 和 `--max-discards` 参数在分区表或开启分区计算组件场景下不生效的问题。

* 修复导入目录或文件为空时，出现报错而非正常退出的问题。

* 修复导入包含错位数据的 POS 文件时不报错的问题。

* 修复 `--pos` 格式下导出包含中文的数据时，报错 start > length() 的问题。
