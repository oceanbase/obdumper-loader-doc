# 导数工具 V4.3.6

本次发版的导数工具 V4.3.6 主要围绕自动列映射能力增强、导入导出功能扩展、HBase/OBKV 场景支持完善、内存与稳定性优化等方面进行改进，同时集中修复了一批已知问题，进一步提升工具在多场景迁移导入导出中的兼容性、稳定性和易用性。

## 新增特性

* 支持列自动映射导入场景下，源文件与目标表的列数量不一致时仍可正常导入，提升了对非标准数据文件的兼容能力。

* 支持列自动映射文件在无表头列信息时，按列顺序进行匹配导入，减少了用户对数据文件的额外预处理成本。

* 将列自动映射功能扩展至 SQL 和 AVRO 格式文件导入，进一步增强了导入能力的通用性。

* 调整 `--parallel` 参数默认值，由 1 提升为 20，以优化任务并行处理能力。

* 新增 `--exclude-object-types` 选项，支持在导入导出过程中过滤指定类型的数据库对象。

* 新增 `--column-case-sensitive` 选项，支持在导出 CSV 格式文件时指定列名大小写模式。

* 新增 `--hbase-cf` 选项，用于指定写入 HBase 时的 ColumnFamily 值，以支持 OBKV-HBase 导入场景。

* 新增 `--hbase-rowkey` 选项，用于指定写入 HBase 时的 rowkey 列名，以支持 OBKV-HBase 导入场景。

* 新增 `--hbase-rowkey-reverse` 选项，用于指定写入 HBase 时 rowkey 是否需要反转，以满足不同 OBKV-HBase 场景需求。

* 在 POS 格式文件中新增 `--skip-header` 选项，支持跳过首行数据。

* 在 CSV 格式下，支持在未指定 `--skip-header` 的情况下，结合 `--retain-empty-files` 选项导出列名。

* 将 `--ignore-escape` 选项由仅适用于导入扩展为导入导出通用选项，支持用户按需选择是否转义。

* 在导出表定义时，支持通过 `--sequence-policy` 控制列起始值生成策略，其中 preserve 表示按当前序列进度导出，restart 表示按建表时起始值导出。

* 新增 buffer 大小限制机制，用于控制内存占用，降低内存膨胀和数据导入过程中出现 OOM 的风险。

## 缺陷修复

* 修复了旁路导入不指定租户名会导致程序卡住的问题。

* 修复了 Oracle 租户导出 number 类型数据变成科学计数法的问题。

* 修复了在 Oracle 兼容模式下将 -D 选项为必选的问题，恢复为可选状态。

* 修复了 MySQL 模式下大写的主键匹配列位置不能正确获取出现报错的问题。

* 修复了 OSS 导入数据报错 The object type name is null 的问题。

* 修复了使用不存在的目录导出依旧会报错 The output directory is not empty 的问题。

* 修复了导入包含 timeout 等字符串的特殊用户出现 --replace-object 和 --drop-object 选项失效的问题。

* 修复了导出--column-quote-mode=none 选项导出时未指定 --escape-character 选项直接报错问题，改为输出警告。

* 修复了启动脚本 GC_OPTS 报错 `VM option 'UseG1GC' is experimental and must be enabled via -XX:+UnlockExperimentalVMOptions` 的问题。

## 依赖库升级

* 将将组件 commons-compress 的版本从 1.22 升级到 1.26.0。

* 将组件 oceanbase-client 的版本从 2.4.14 升级到 2.4.17。

* 将组件 hadoop 的版本从 3.3.6 升级到 3.4.0。
