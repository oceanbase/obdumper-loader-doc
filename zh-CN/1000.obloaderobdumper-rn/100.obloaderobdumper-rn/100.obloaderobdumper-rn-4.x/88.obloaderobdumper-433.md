# 导数工具 V4.3.3

本次 2 月发版的导数工具 V4.3.3 旨在提升导出速度和稳定性。

## 新增功能

* 快照导出的场景，内部实现改为直接查询宏块范围，性能可以提升大约 3~4 倍。

* 对于 OceanBase 数据库 V2.2.27 及之前版本，进行查询表元数据信息的相关操作加速，部分场景可以提升 20 倍。

* 任务分片和数据导出改为并行执行，避免大表卡在任务分片阶段长时间不开始导出。

* 修改 `--truncate-table` 参数的行为，仅对存在数据文件的表执行 Truncate 操作，并且增加二次确认，以提示风险。

* 执行的所有 SQL 增加注释，方便用户标识 SQL 来源。

* 增加 `--yes` 选项忽略交互式确认，方便集成。

* 增加检查项：导出 `-f` 选项指定为具体文件时，不应该与 `--block-size` 选项同时使用。

## 兼容性变动

* 无论导入单张表还是多张表，使用 `--truncate-table` 选项时，均增加二次确认以降低风险。

## 缺陷修复

1. 修复导入已存在的对象时，报 NPE 错误的问题。

2. 修复导出的存储过程未包含 sql security 信息的问题。

3. 修复导入 CSV 文件时，报错 negative size 的问题。

4. 修复多表整库导出时，遇到会话数管理溢出导致任务失败的问题。

5. 修复导入日志 ignore 和 excute truncate table 出现计数不连续的问题。
