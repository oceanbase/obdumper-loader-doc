# 导数工具 V4.3.3

本次 3 月发版的导数工具 V4.3.3 旨在提升导出速度和稳定性。

## 新增功能

* **导出性能提升**

  * 优化快照导出时查询宏块范围的技术方案，在大表场景下性能提升约 3~4 倍。

  * 优化导出过程中多线程管理效率，多表导出场景下带来约 5% 左右的性能提升。

* **元信息查询加速**

    对于 OceanBase 数据库 V2.2.27 及之前版本，进行查询表元数据信息的相关操作加速，部分场景可以提升 20 倍。

* 优化任务启动

    任务分页和数据导出改为并行执行，解决大表导出时分片阶段耗时过长的问题。

* 执行的所有 SQL 增加注释，方便用户通过 SQL Audit 标识 SQL 来源。

* 增加检查项：导出 `-f` 选项指定为具体文件时，不应该与 `--block-size` 选项同时使用。

## 兼容性变动

* `--truncate-table` 和 `--delete-from-table` 参数行为修改，均增加二次确认以降低风险。同时增加 `--yes` 选项跳过交互式确认，方便集成。

## 缺陷修复

1. 修复导入已存在的对象时，报 NPE 错误的问题。

2. 修复导出的存储过程未包含 sql security 信息的问题。

3. 修复导入的 CSV 文件大小恰好是 `--block-size` 指定值的整数倍时，报错 negative size 的问题。

4. 修复结构导出过多表对象时，可能发生的数据库连接池耗尽而导致任务失败的问题。

5. 修复导入日志 ignore 和 excute truncate table 出现计数不连续的问题。

6. 修复 `-f` 指定为具体文件时，开启并行写失效的问题。

7. 修复快照导出时，任务分页性能相比 V3.x 有较大回退的问题。

8. 修复 `--auto-column-mapping` 导致 `--replace` 参数失效的问题。

9. 修复 `-f` 指定为具体文件时，最终导出的文件存在后缀名重复的问题。

10. 修复导出格式为 ORC 时，如果目标表为空表且指定了 `--retain-empty-files`，导出目录下并未生成空文件的问题。
