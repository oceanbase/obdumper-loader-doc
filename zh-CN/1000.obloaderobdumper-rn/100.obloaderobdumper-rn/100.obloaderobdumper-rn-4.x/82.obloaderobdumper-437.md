# 导数工具 V4.3.7

本次发版的导数工具 V4.3.7 主要围绕认证能力增强、空间数据导入支持、导入时表重命名与对象跳过、Oracle 模式 DDL 导出完善、大文件与分片场景稳定性提升、Windows 平台原生兼容等方面进行改进，同时集中修复了一批已知问题并升级关键依赖，进一步提升工具在多场景迁移导入导出中的兼容性、稳定性和易用性。

## 新增特性

* 新增 `--remap-table` 选项，支持在导入时将源端表名映射为目标端不同的表名。适用于跨环境迁移（如测试→生产）表命名规范不一致，或需要将同一份数据导入到不同目标表的场景，无需手动修改导出文件或 SQL 脚本。

* 新增 `--skip-existing-object` 选项，Schema 导入时自动跳过目标库中已存在的对象，并在 Summary 中以 SKIPPED 状态展示。适用于增量 Schema 导入或任务中断后重新执行的场景，避免因对象已存在导致导入失败，同时清晰标记哪些对象被跳过。

* 支持 MySQL `caching_sha2_password` 认证方式。当 OceanBase 数据库账号启用了更高安全级别的 `caching_sha2_password` 认证插件时，导数工具自动完成认证握手，用户无需手工修改连接参数即可正常使用，降低认证配置门槛。

* 支持从 Parquet 等扁平文件中导入 WKT 格式的空间几何数据到 MySQL POINT/GEOMETRY 类型列，并正确适配 SRID 4326 的经纬度轴序。适用于地图、物联网等业务将空间位置数据从数据湖（如 OSS、S3）批量导入 OceanBase 的场景，无需额外的数据格式转换。

* 支持从输入流以及 ZIP、JAR URL 中读取 Manifest 文件。适用于 CI/CD 流水线或容器化部署等自动化场景，使导数工具能够在更多运行环境中正确识别版本和配置信息。

* 全面提升 Windows 平台兼容性，消除对 Hadoop Native 组件的依赖，修复路径处理、文件命名和检查点文件等多项 Windows 环境问题。Windows 用户无需额外安装 Native 依赖即可直接使用导数工具，文件路径含空格、特殊字符或多盘符等场景均可正常工作。

* 增强启动审计日志，自动将脱敏后的完整启动命令与解析参数写入日志文件。适用于批量调度、自动化运维等无法直接查看终端输出的场景，方便事后回溯执行配置和定位问题。

## 缺陷修复

* 修复了旁路导入未检查 beginFuture 服务端失败状态，以及运行时依赖不兼容可能导致任务卡住的问题；同时补充失败数据字节区间日志。

* 修复了文件合并任务启动时未清理残留 `.mtmp` 临时文件的问题。

* 修复了导出文件路径缺失时报错不明确，以及指定包含多个点号的文件名时名称被截断的问题。

* 修复了 ORC 文件滚动 Stripe 前未关闭 RecordReader 导致 S3 连接泄漏的问题，并将对象存储连接请求超时时间调整为 5 分钟。

* 修复了控制文件中嵌套 REPLACE 函数丢失列值并错误移除换行符的问题。

* 修复了 CUT 文件在转义行分隔符、空行切分边界、文件尾切分以及 trail delimiter 缓存场景下的数据丢失或内存增长问题。

* 修复了 CSV 文件的空 `--null-string`、文件末行无换行符以及 CRLF 跨切分边界场景下的解析问题。

* 修复了 Oracle 模式下使用 `--query-sql` 导出 DATE 类型时格式不正确的问题。

* 修复了 Oracle TYPE 与 TYPE BODY 定义在类型修饰符之后无法正确拆分的问题。

* 修复了 OceanBase Oracle 模式下同名 NOT NULL 约束误过滤普通索引，以及同名函数索引未被保留的问题。

* 修复了 OceanBase Oracle 模式下导出视图时遗漏 FORCE 和 WITH READ ONLY 子句的问题。

* 修复了 `--mix` 模式下 UPDATE/DELETE 字面量连续空格被压缩、REPLACE 和前置注释 DML 处理不正确，以及版本注释触发器被错误拆分的问题。

* 修复了 JVM heap 的 committed 采样值大于 max 时导入任务被错误终止的问题。

* 修复了 OBLD 版本标记未以 SQL Hint 形式保留的问题。

* 修复了 Oracle Schema 枚举时未过滤系统 Schema 的问题。

* 修复了 `--server` 导出场景下 `secure_file_priv` 为 NULL 时出现异常的问题。

* 修复了导出间隔分区表时分区元数据来源选择不正确的问题。

* 修复了多 Schema 任务中租户级用户和角色被重复导出，以及 `--all` 对象路由不正确的问题。

* 优化了 Oracle DDL 元数据查询，避免按对象重复查询造成查询量放大。

## 漏洞修复

* 修复 Kryo 反序列化安全风险，限制仅反序列化已注册的受信类型，降低不安全反序列化风险。

* 升级存在安全风险的第三方依赖，并移除 Commons Collections 3 运行时依赖。
