# 导数工具 V4.3.4

本次 7 月发版的导数工具 V4.3.4 旨在初步支持逻辑迁移场景、适配 OBServer V4.3.x 新的数据类型、提高 ORC 导入性能以满足业务需求，以及修复若干已知缺陷。

## 新增特性

* 逻辑迁移：新增支持导入导出用户、权限等对象定义和授权语句，以初步满足逻辑迁移场景需求。

* 性能提升：ORC 文件的读取方式改为并行分片读写，性能提升 10 倍以上。

* IPv6 支持：已适配和支持使用 IPv6 地址导入和导出数据。

* 适配 OBServer V4.3.x：验证所有查询是否兼容，并新增支持 OceanBase 数据库 MySQL 兼容模式下的 roaringbitmap、vector、sparsevector、array 和 map 数据类型。

* 适配 Clickhouse：支持导入 CK 生成的 CSV 文件，解决布尔值字段的兼容问题。

* 体验改进

  * 导入过程中增加内存水位控制，减少内存溢出概率。

  * 导入过程中增加 GC 信息打印，帮助定位导入性能瓶颈。

  * CSV 文件导入报错增加文件位点打印信息，帮助定位出错字符位置。

* 新增启动参数

  * 新增 `enable.partition.calculation`：用于控制是否开启分区计算，默认开启。
  
  * 新增 `enable.contain.definer`：用于控制存储过程和函数定义导出是否包含 definer 信息，默认开启。
  
  * 新增 `enable.table.index`：用于控制 OceanBase 数据库 Oracle 兼容模式下，表定义导出是否包含索引信息。默认开启。
  
  * 新增 `enable.table.comment`：用于控制 OceanBase 数据库 Oracle 兼容模式下，表定义导出是否包含表注释信息。默认开启。
  
  * 新增 `enable.table.column.comment`：用于控制 OceanBase 数据库 Oracle 兼容模式下，表定义导出是否包含列注释信息。默认开启。

## 兼容性变动

* `--table='*' --ddl` 如果未能匹配到任何对象，行为由之前的报错改为正常退出。

## 缺陷修复

* 修复导入过程中 `--max-tps` 控制不准确的问题。

* 修复导出过程中使用 exclude 指令排除主键或唯一键后报错 "The column type is null" 的问题。

* 修复 OceanBase 数据库 Oracle 兼容模式下，只读实例导出对象时报错 "may not perform insert/delete/update operation inside a READ ONLY transaction" 的问题。

* 修复 OceanBase 数据库 Oracle 兼容模式下，使用 mix 模式或 sql 模式导入时，无法正确解析 SQL 内容中带有反斜杠的案例，进而陷入死循环并最终内存溢出的问题。

* 修复控制文件扩张列导致分区计算时发生 ArrayOutOfBoundException 的报错问题。

* 修复导入过程中 bad 和 discard 记录有小概率不被记录在日志文件中的问题。

* 修复不指定转义符的情况下，导入 CSV 文件过程中可能出现的逻辑切分位置计算错误而导致导入失败的问题。

* 修复无任何对象需要导出情况下，组件报错退出的问题。

* 修复导入过程中可能出现大量 "Calculate leader of table failed, treat it as non-partition table." 报错刷屏的问题。

* 修复导出到 OSS 且 OSS 不支持 multi-chunk encoding 情况下，导数工具显示导出成功但实际未有数据写入到 OSS 的问题。

* 修复 `--replace-object` 参数对 type 对象无效的问题。

* 修复导出以分号结束的 Type 对象后再导入失败，并报错 "Syntax Error" 的问题。

* 修复 OceanBase 数据库 Oracle 兼容模式下，无法在小写用户名以及小写 Schema 场景下导入导出的问题。

* 修复在导入导出时未指定 `--table`/`--all` 选项而导致报错 NPE 的问题。

* 修复导入列数量不匹配时报错空异常的问题。

* 修复无法指定文件名将数据导出至 OSS 文件的问题。

* 修复导出序列时报错 "The next value is bigger than the max value" 的问题。

* 修复 OceanBase 数据库 Oracle 兼容模式下，快照导出临时表时报错 "No valid replicas" 的问题。

* 修复不能给导数组件分配超过 48GB 内存的问题。

* 修复 `--server` 模式下导入失败但导数组件显示成功的问题。

* 修复导出数据时，同一时刻导出负载集中在某一张表或某张表的某几个分区上的问题。

## 漏洞修复

* 升级 obkv-table-client 版本以解决 netty-handler-4.1.100.Final 组件关联的 CVE-2025-24970 漏洞。

* 升级 Avro 版本以解决 avro-1.11.3 组件关联的 CVE-2024-47561 漏洞。

* 将 obkv-table-client 组件的版本从 V1.2.13.1 升级到 V1.2.13.2。

* 将 Avro 组件的版本从 V1.11.3 升级到 V1.11.4。
