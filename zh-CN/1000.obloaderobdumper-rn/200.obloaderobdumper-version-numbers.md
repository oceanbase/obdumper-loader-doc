# 版本号规则

本文主要介绍导数工具的版本号规则及其含义。

随着导数工具的不断迭代和优化，导数工具会不定期发布新的版本。不同版本的导数工具在功能及特性方便的差异可能会很大，因此需要识别导数工具版本号，以便获取准确的文档信息。

导数工具的版本格式通过 V.x.y.z.f 表示，其中：

* x 表示主要的大版本。该版本通常会有架构升级或较大的新功能发布。

* y 表示计划迭代版本。该版本是正常迭代计划，包含重要功能或特性更新和提升。

* z 表示发布更新版本。该版本包含少量功能或特性更新，以及对已知问题进行修复。

* f 表示补丁升级版本。第四位版本号针对因功能特性或修复问题需要发布高版本号的场景。

## 查看版本号

解压导数工具软件包并进入脚本所在的目录，执行以下命令查看版本号。

* 查看 OBLOADER 的版本

    ```shell
    [xxx@xxx /ob-loader-dumper-4.x.x-RELEASE/bin]
    $./obloader --version
    Version: 4.x.x-RELEASE
    ```

* 查看 OBDUMPER 的版本

    ```shell
    [xxx@xxx /ob-loader-dumper-4.x.x-RELEASE/bin]
    $./obdumper --version
    Version: 4.x.x-RELEASE
    ```
