# Startup parameters

Startup parameters are used to adjust some default behaviors of the data export tool. You can usually leave them unchanged. This topic describes the startup parameters supported by the data export tool.

| Parameter | Description | Default value |
|----------|------------|--------------------|
| enable.partition.calculation | Specifies whether to enable partition calculation.  |Enabled |
| enable.contain.definer | Specifies whether to include the definer information when exporting the definitions of stored procedures and functions.  |Enabled |
| enable.table.index | Specifies whether to include index information when exporting table definitions in the Oracle compatible mode of OceanBase Database.  |Enabled |
| enable.table.comment | Specifies whether to include table comment information when exporting table definitions in the Oracle compatible mode of OceanBase Database.  |Enabled |
| enable.table.column.comment | Specifies whether to include column comment information when exporting table definitions in the Oracle compatible mode of OceanBase Database.  |Enabled |

To modify a startup parameter, edit the `obloader.bat` file in the `bin/windows` directory or the `obloader` file in the `bin` directory of the tool installation directory.
