# Versioning rules

This topic describes the versioning rules of OBLOADER & OBDUMPER.

New versions will be released from time to time as OBLOADER & OBDUMPER is continuously iterated and optimized. The features of OBLOADER & OBDUMPER may differ significantly from one version to another. Therefore, you must confirm the required version to obtain the correct document information.

The version numbers of OBLOADER & OBDUMPER are in the V.x.y.z.f format.

* `x` indicates a major version, which generally involves an architectural upgrade or a release of major features.

* `y` indicates a planned iteration version, which involves an update or optimization of major features in a normal iteration plan.

* `z` indicates an updated version, which involves a few updates in features and fixes known issues.

* `f` indicates a patch upgrade version. It is in the fourth place and suffixed to form a later version number that identifies feature updates or bug fixes.

## View the version

After you decompress the software package of OBLOADER & OBDUMPER, go to the script directory and run the following command to view the version number:

* View the version of OBLOADER

    ```shell
    [xxx@xxx /ob-loader-dumper-4.x.x-RELEASE/bin]
    $./obloader --version
    Version: 4.x.x-RELEASE
    ```

* View the version of OBDUMPER

    ```shell
    [xxx@xxx /ob-loader-dumper-4.x.x-RELEASE/bin]
    $./obdumper --version
    Version: 4.x.x-RELEASE
    ```
